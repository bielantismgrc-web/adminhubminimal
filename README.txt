MINIMAL ADMIN HUB

Instalação no seu próprio jogo:
1. Abra o Roblox Studio.
2. Crie um Script em ServerScriptService e cole server_admin.lua.
3. Crie um LocalScript em StarterPlayer > StarterPlayerScripts e cole client_admin.lua.
4. No script do servidor, troque 123456789 pelo seu UserId numérico.
5. Teste usando Play.

Comandos:
;char NomeDoJogador
;char me

O comando copia a descrição/avatar aplicada ao Humanoid do jogador alvo.
O sistema só aceita chamadas de usuários listados em ADMIN_USER_IDS.
Este projeto é para o seu próprio jogo no Roblox Studio; não é um script para Xeno
nem para obter permissões em experiências de terceiros.
